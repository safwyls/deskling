# Hardware

`crowpanel_retainer.step` / `.stl`: the one printed part, a ring that grips the CrowPanel 1.46" rotary
display's rear body and holds it tipped 30° toward you. About 60 × 62 × 43 mm. Printed in translucent
PETG it carries the knob's LED ring down into the base as a glow.

The build guide on the website covers printing it: `site/pages/wiki/print.html`.
