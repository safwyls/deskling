# Hardware

The stand is two printed parts:

| File | Part |
| --- | --- |
| `crowpanel_shell.step` / `.stl` | The shell you see, about 65 × 91 × 53 mm. Its top is tipped 30° toward you with a round opening; the knob rests on the rim. Printed in translucent PETG it carries the knob's LED ring down into the base as a glow. |
| `crowpanel_retainer.step` / `.stl` | The bracket that sits inside the shell and grips the CrowPanel 1.46" rotary display's rear body (about 60 × 63 × 43 mm). |

The two STEP files don't share an origin, so they don't line up if you import both.

The build guide on the website covers printing them: `site/pages/wiki/print.html`.
